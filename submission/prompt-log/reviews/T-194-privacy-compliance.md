# T-194 privacy/compliance review: public snapshot (deploy/make_public_snapshot.sh, commit 6904b41, run at HEAD 85bcd22)

Verdict: **fail**. There is 1 blocker, 2 majors, 4 minors and 1 nit.

I found no secrets, no `.env` file and no real patient data in the snapshot. The plain, escaped and URL-encoded forms of the tailnet hostname, its tail label, the tailnet IPs and the full work email are absent from every text file and from the inflated `.git` objects. The commit identity is correct. The snapshot still fails to deliver what the card promises, for these reasons:

- **Blocker: the hostname is in screenshots.** At least 11 board screenshots in `artifacts/screenshots/` show the full tailnet URL (host, tail label, `<redacted-private>`, ports) in the board header. The scan reads PNGs as latin-1 bytes, so it cannot see pixels. It still reports "0 hits", and SNAPSHOT.md tells Chris to publish. Once the repo is pushed, the exposure cannot be undone.
- **Major: work email in the scanner's own source.** In the snapshot, `deploy/snapshot_tool.py:128-129` spells the work email's local part and domain in a `[.]` regex form. The scan does not catch its own spelling. This is the same class of leak as T-187 r2 major 1.
- **Major: `make test` fails on a clone of the public repo.** Three tests check commit provenance and fail in a single-commit history. The README says "Exit 0 means all passed". This is outside my lens; I filed it because the brief asked me to check what the README tells users to run.

Minors:

- Device names were not redacted: the Mac's node name, the phone's model name and a `tailscale status` row.
- The redaction breaks once QA's pending `finalize_prompt_log.py` rewrite is committed. It fails closed.
- The redaction quietly removed the tailnet-peer case from the D-036 test.
- AC 1 is ticked even though the NEEDS_CHRIS clause is still open on T-195.

T-187 major 2 content (job-application paths, <outside project> quotes, the PDF file name carrying Chris's name) is still in the snapshot. SNAPSHOT.md says plainly that the script does not handle it, so I note it here and do not grade it (T-193).
